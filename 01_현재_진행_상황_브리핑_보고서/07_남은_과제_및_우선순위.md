## 팀 내 최종 확인이 필요한 불일치 사항

아래 항목은 담당자별 전달 내용과 저장소 문서/코드가 서로 다르거나, 아직 팀 협의로 확정되지 않은 값입니다. 임의로 하나를 정답으로 확정하지 않고 그대로 남겨둡니다.

| 항목 | 현재 상태 |
|---|---|
| Vision class명 (`bag` vs `backpack`) | Data Contract는 `backpack`으로 고정. Vision 쪽 실제 코드 미완성으로 일치 여부 확인 전 |
| 최종 카메라 하드웨어 (Razbot 자체 카메라 vs ESP32-S3 Camera) | `HARDWARE_REFERENCE.md`에는 ESP32-S3 언급 없음, 조은수 전달 내용에는 언급 있음 — 하드웨어 구조 최종 확인 필요 |
| 객체 확정 confidence threshold | 가이드 문서상 예시값(0.6)만 존재, 팀 조정 가능 값으로 명시되어 미확정 |
| 연속 검출 횟수 | 팀 논의 중 2~3회가 검토되었으나 최종 확정 아님 |
| Ultrasonic 정지 거리 | 코드상 20cm는 자리표시자(TBD), 실물 센서 테스트 후 확정 필요 |
| 실제 하드웨어 Line Tracking 구현 상태 | 현재 Mock 상태머신으로만 구현, 실물 라인트레이싱 센서 연동 전 |
| `lost_items` anon INSERT 권한 확장 여부 | 현재 Data Contract 문서는 service_role 필요로 명시, anon 확장 여부 팀 협의 필요 |
