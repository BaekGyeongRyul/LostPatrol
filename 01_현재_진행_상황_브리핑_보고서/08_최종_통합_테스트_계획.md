# 08. 최종 통합 테스트 계획

각 담당자가 자기 코드를 연결한 뒤, 아래 순서대로 통합 테스트를 진행합니다. 웹은 실제 배포된 https://BaekGyeongRyul.github.io/LostPatrol/ (또는 로컬 `npm run dev`)로 열고, Supabase Table Editor로 실제 행 변화를 함께 확인합니다.

## Robot

- [ ] Web에서 Forward → Supabase command 생성 → Raspberry Pi command polling → 실제 로봇 직진 → status 완료 처리
- [ ] Left → 제자리 좌회전
- [ ] Right → 제자리 우회전
- [ ] Stop → 즉시 정지
- [ ] patrol_start → Line Tracking 자동순찰 시작
- [ ] patrol_stop → 자동순찰 종료
- [ ] heartbeat → Web ONLINE 유지
- [ ] Pi 연결 종료 → 약 15초 후 Web OFFLINE

## Safety

- [ ] Ultrasonic 장애물 감지 → 안전정지

## Vision

- [ ] 가방 탐지 (Bounding Box / Confidence / Class 확인)
- [ ] 우산 탐지 (Bounding Box / Confidence / Class 확인)
- [ ] 물병 탐지 (Bounding Box / Confidence / Class 확인)

## Vision + Supabase

- [ ] 객체 후보 확정
- [ ] 이미지 Capture
- [ ] Storage 업로드
- [ ] lost_items INSERT
- [ ] image_url 저장
- [ ] Web Lost Items에 표시

## Web

- [ ] 분실물 상세정보 확인
- [ ] 상태 변경
- [ ] Supabase status UPDATE

## 최종

- [ ] 수동조작 시연
- [ ] 자동순찰 시연
- [ ] 분실물 탐지 시연
- [ ] 웹 자동등록 확인
- [ ] 실패 상황 Backup Plan

---

현재 위 항목 중 **Web ↔ Supabase 관련 항목(수동/자동순찰 명령 왕복, heartbeat ONLINE/OFFLINE, 분실물 상태 변경)은 Mock Controller 기준으로 확인 완료**된 상태이며, 나머지 실제 하드웨어·Vision 관련 항목은 [07. 남은 과제 및 우선순위](07_남은_과제_및_우선순위.md)에 따라 순차 진행 예정입니다.
