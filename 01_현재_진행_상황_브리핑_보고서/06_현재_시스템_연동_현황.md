# 06. 현재 시스템 연동 현황

## [완료]

```
Web ↕ Supabase
```
웹의 모든 명령(수동 8종 + patrol_start/patrol_stop)이 실제 `robot_commands`에 INSERT되고, `robot_status`/`lost_items`를 실제로 조회·갱신하는 것을 확인했습니다.

```
Robot Mock Controller ↕ Supabase ↕ Web
```
Mock Controller가 anon key로 명령을 polling하고, heartbeat를 5초마다 갱신하며, 웹에서 ONLINE/OFFLINE 표시가 정상 동작하는 것을 확인했습니다.

```
GitHub Collaboration
GitHub Pages
```
공용 Repository + Collaborator 구조, Data Contract 문서화, GitHub Actions를 통한 자동 배포(https://BaekGyeongRyul.github.io/LostPatrol/)까지 완료했습니다.

```
Camera → Storage
```
`lost-item-photos` 버킷에 anon SELECT/INSERT/UPDATE RLS 정책을 적용해 기존 403 오류를 해결했고, `upload_capture()` 재실행으로 실제 이미지 업로드(`storage.objects` 파일 확인 + 공개 URL 200 응답)까지 검증했습니다.

```
Safety Monitor ↔ Supabase
```
`safety_status`/`patrol_events` 신규 테이블 구축(2026.08.25) 후, `safety_monitor.py`의 실제 갱신·이벤트 로그 기록까지 확인했습니다.

```
Vision 3종 분류 모델 구축
```
가방/우산/물병 3종을 서로 구별할 수 있는 YOLO 모델까지 구축했습니다 (조은수 담당자 보고 기준, 저장소 코드 반영은 아직 전).

## [부분 완료 / 진행 중]

```
Vision → Razbot Camera 실제 입력
```
현재는 PC/Webcam 기준으로 모델을 검증한 단계이며, 팀 협의로 확정된 Razbot 카메라 1대를 실제 입력으로 연결하는 작업은 아직 진행 전입니다.
