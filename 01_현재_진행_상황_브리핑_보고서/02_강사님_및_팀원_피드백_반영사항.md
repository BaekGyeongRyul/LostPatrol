# 02. 강사님 및 팀원 피드백 반영사항

## 5-1. 웹사이트 디자인 개선

강사님께 보여드릴 웹사이트의 완성도를 높이기 위해, 단순 프로젝트형 UI가 아니라 실제 서비스 웹사이트처럼 보이도록 디자인 방향을 변경했습니다.

현대자동차 공식 웹사이트를 **디자인 모티브 및 참고 사례**로 삼아, 기업형 웹사이트의 다음 특징을 참고하도록 Claude Code에 요구사항을 전달해 LostPatrol 웹을 전면 리디자인했습니다.

- 넓은 레이아웃
- 밝은 흰색/회색 계열 톤
- 상단 Navigation
- 정돈된 정보 배치
- 깔끔하고 직관적인 화면

현대자동차의 로고나 고유 디자인 요소를 그대로 복제한 것이 아니라, 실제 기업 웹사이트 수준의 레이아웃과 가독성을 참고 사례로 삼았습니다. Robot Control 화면의 차량 컨트롤러(`VehicleController.jsx`)도 코드 내 주석에 "특정 브랜드 차량 디자인을 참고하지 않은 단순 도형(둥근 사각형 차체)"이라고 명시된 generic한 실루엣으로 구현되어 있습니다.

## 5-2. Footer — 팀원 이름 표시

강사님께서 팀원 이름이 웹사이트에 표시되면 좋겠다는 피드백을 주셔서, 페이지 하단 Footer(`src/components/layout/Footer.jsx`)에 아래 내용을 추가했습니다.

```
COPYRIGHT ⓒ 2026 LostPatrol Team · 백경률 · 이윤정 · 조은수 ALL RIGHTS RESERVED
```

## 5-3. Robot Control UI 단순화

팀원 피드백: "Robot Control에서는 컨트롤러가 핵심이므로 컨트롤러가 화면을 크게 차지하고, 불필요한 요소는 줄이는 것이 좋겠다."

이를 반영해:

- Robot Control 화면을 단순화
- 조작 컨트롤러(`VehicleController`)를 화면 중심에 크게 배치
- 일반적인 방향키 형태 대신, 실제 차량/로봇 조작을 연상할 수 있도록 자동차 모티브의 컨트롤러 UI 적용
- 불필요한 정보 영역 축소

## 5-4. 조작 방식 — PC/모바일 동시 지원

PC와 모바일 사용 환경을 모두 고려했습니다.

| 환경 | 조작 방식 |
|---|---|
| PC | 키보드 방향키(↑↓←→), Space(정지) |
| 공통 | 마우스 클릭 |
| 모바일 | 터치 |

즉 키보드, 마우스, 터치 방식 모두 동일한 command 처리 흐름을 통해 로봇에 명령을 전달할 수 있도록 구현했습니다.

### 로봇 command 규격 (8종, 고정)

| command | 의미 |
|---|---|
| `forward` | 직진 |
| `backward` | 후진 |
| `left` | 제자리 좌회전 |
| `right` | 제자리 우회전 |
| `stop` | 즉시 정지 |
| `capture` | 촬영 |
| `patrol_start` | 라인트레이싱 자동순찰 시작 |
| `patrol_stop` | 자동순찰 종료 |

`left`/`right`는 전진하며 회전하는 것이 아니라 **제자리 회전**을 의미하며, 이 규격은 Web/Robot 양쪽 코드와 `docs/02_SUPABASE_DATA_CONTRACT.md`에서 동일하게 확인됩니다.
