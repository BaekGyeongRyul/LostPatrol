# 01. 프로젝트 전체 진행상황

## 프로젝트 개요

**프로젝트명**: LostPatrol

**목적**: 공공장소를 순찰하는 로봇이 분실물 후보를 탐지하고, 관련 정보를 Supabase에 저장하여 관리자 웹사이트에서 조회·관리할 수 있도록 하는 Physical AI 기반 분실물 탐색·순찰 로봇 프로젝트

**전체 구조**

```
[Web]  ──  Supabase(robot_commands / robot_status / safety_status / patrol_events / lost_items / Storage)  ──  [Raspberry Pi / Razbot + Arduino 안전센서]
                              ▲
                              │
                    [OpenCV + Roboflow + YOLO]
```

Web과 Raspberry Pi, Web과 AI 파이프라인은 서로 직접 통신하지 않고, Supabase가 유일한 중앙 데이터 허브 역할을 합니다.

## 최종 분실물 종류 (3종 고정)

팀 최종 결정으로 탐지 대상 객체는 3종으로 제한했습니다.

| Data Contract 값 | 사용자 표시 |
|---|---|
| `umbrella` | 우산 |
| `bottle` | 물병 |
| `backpack` | 가방 |

**선정 이유**
- 일상에서 분실 가능성이 높은 대표적인 물품
- 물체 간 형태적 차이가 비교적 명확해 탐지 정확도를 높이기 쉬움
- 짧은 프로젝트 기간 안에 데이터 수집·라벨링·학습·검증을 현실적으로 수행하기 위해 범위를 제한
